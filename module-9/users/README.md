# ToriloShop - Django Project

## Project Description

ToriloShop is a Django-based online shop built as part of Module 7.
It demonstrates URL routing, views, and app registration in Django.

## Features Implemented

- **home()** → `/` — Welcome page for the shop
- **product_list()** → `/products/` — Lists available products
- **about()** → `/about/` — Information about ToriloShop
- **custom_404()** → Any unknown URL — Custom 404 error page

## Setup Instructions

1. Unzip the project folder
2. Create a virtual environment:
   python -m venv venv
3. Activate it:
   venv\Scripts\activate
4. Install dependencies:
   pip install django
5. Run the server:
   python manage.py runserver
6. Open browser at `http://127.0.0.1:8000/`
